- 不适用字段使用 `N/A:<reason>`；不得使用空值、`UNKNOWN` 或 `TBD`。

- `dedicated_inventory_pr=#65` 是唯一 Stage A inventory PR identity；后续 tasks 不得恢复 bootstrap placeholder。
