## Stage A closeout rules

- Stage A 在唯一 dedicated inventory PR `#65` 内用满 3 个 tasks；不得新增第 4 个 inventory task。
- 11 个 mandatory areas 均有 ledger row；runtime、tests、gateway、coordination、Host、persistence 与 ops consumers 已进入逐列事实记录。
- `BLOCKED` 均记录缺失证据、owner、解除条件与 rollback；`KEEP` 仅用于已验证且应长期保留的 ownership / verification boundary。
- 不适用字段使用 `N/A:<reason>`；不得使用空值、`UNKNOWN` 或 `TBD`。
- `EVIDENCE_MISSING:<具体证据>` 仅用于 `BLOCKED` row 的 parity/real-host/blocker 字段。
- Stage A 未修改 production code、package exports、runtime behavior 或 consumer ownership。
